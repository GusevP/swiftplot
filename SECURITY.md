# Security

## Supported versions

Only the latest release of `swiftplot`, `@swiftplot/react` and `@swiftplot/vue` gets security fixes. The three
packages are released together under one version, and a fix ships as a new release.

## Reporting a vulnerability

Report it privately through GitHub: on the repository's Security tab, choose
[Report a vulnerability](https://github.com/GusevP/swiftplot/security/advisories/new).
Please do not open a public issue, discussion or pull request for it.

Include the affected version, what an attacker can do, and the smallest page or code that shows it.

## What to expect

The report is answered in the advisory, where the fix and its release are discussed. Once a fixed version is
published, the advisory is made public with credit to the reporter, unless they ask not to be named.
